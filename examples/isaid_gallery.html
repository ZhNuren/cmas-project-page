iSAID-5i gallery: random queries, text-only vs. text + CMAS (SAM3)

Classes: ship, basketball court, soccer ball field (the classes of the released steering packs; 5 annotated support images per class, supports excluded). Within these classes the queries are a random sample (seed 2027) of the iSAID-5i val queries, not hand-picked, plus random images where the class is absent. Present: mean Dice text-only 0.10 → text + CMAS 0.35 (24 queries; queries with Dice > 0: 3 → 11). Absent: correct empty output 6/6 → 5/6. The pack classes were chosen as showcase classes where text-only SAM3 fails, so this gallery is not representative of the dataset average (iSAID-5i: Dice 0.389 → 0.523 over all classes, paper Table 2). Masks re-predicted with the released code and packs (not the paper's saved outputs).
