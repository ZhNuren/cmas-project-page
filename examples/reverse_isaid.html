iSAID-5i: click only vs. click + CMAS (text → click), SAM3

Steering vectors from extra text guidance added to click-only inference: no class name at test time. Per class, five annotated support images: activations with an optimised class-text embedding + click minus the same click alone with SAM3's generic visual prompt; site and α per fold by leave-one-support-out: per fold encoder.3.self_attn (α 1.86) / encoder.1.mlp (1.69) / encoder.1.self_attn (1.84). At test, one random positive click per (image, class) pair, identical in all click arms. Dataset result (paper Tables S11, S13): click 0.562 → 0.593 (+0.031 Dice, 5,234 pairs better / 4,498 worse, p = 4×10−29 over 10,063 pairs; among pairs changing by more than 0.05: 1,730 better / 970 worse); text + click 0.570. Mean of the shown pairs (not representative): click 0.47 → 0.64, text + click 0.56. Masks re-predicted with the paper's test code unchanged (same vectors and clicks); every mask reproduces the stored test record exactly.
